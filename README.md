# Backlog do Módulo de Instrução de Destinações

Página de consulta com as demandas levantadas para o **Módulo de Instrução de Destinações**
(plataforma SPUnet Gestão) que ainda **não entraram em nenhuma história de usuário**.

Serve para ser consultada antes de qualquer conversa sobre o módulo — com a equipe,
com a área de negócio ou com a SERPRO.

Cada item traz o que já se sabe, o que está em aberto e a situação:

- `ABERTO` — ainda não discutido com a equipe.
- `ADIADO` — já levantado e empurrado para depois, com a data em que foi levantado.

No ar em <https://spu-projetoseprocessos.github.io/backlog-modulo-instrucao/>.
